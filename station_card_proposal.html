① 达成率改为「文字 % + 迷你进度条」：把达成率从"一个彩色数字"升级为"有形状的图形化 KPI"（Grafana/FineBI/Excel 看板通用做法），与右侧纯数字（X/Y）在视觉重量上拉开层级，一眼可分。
② 两指标块之间加竖向分隔线：贯穿表头与表体（对应 Ant Design Pro `StatisticCard` 的 `Divider` 分组思路），明确"达成率区"与"数字区"的界限。
③ 达成率块极淡底色聚类 + 数字区保持中性：用 Gestalt 相似性把同组列聚成一束；数字区（分子/分母）用中性墨色，颜色只留给状态（绿/黄/红），符合"颜色编码状态而非装饰"原则。
注：当前实现中达成率仅由 th1 分组头（浅灰底）作区分，该底色不延伸至表体，导致表体内两区块无边界；以上三招即补此缺口。
可落地的 CSS / 渲染改动（复制到 index.html 即可生效） 
/* ===== 新增 CSS（置于 .ap-station-table 相关规则附近） ===== */
/* 达成率：文字 + 迷你进度条，与数字区形成视觉层级 */
.ap-station-table .ap-rate-cell{display:flex;flex-direction:column;align-items:center;gap:3px}
.ap-station-table .ap-rate-bar{width:100%;max-width:54px;height:5px;background:var(--surface-sunken,#eceef1);border-radius:3px;overflow:hidden;margin-top:1px}
.ap-station-table .ap-rate-bar>i{display:block;height:100%;border-radius:3px}
/* 两指标块之间的竖向分隔线（贯穿表头与表体） */
.ap-station-table th.ap-blk-sep,.ap-station-table td.ap-blk-sep{border-left:2px solid var(--c-border,#d7dbe0)}
/* 达成率块极淡底色聚类（Gestalt 相似性） */
.ap-station-table td.ap-rate-band{background:var(--surface-sunken,#fbfcfe)}

/* ===== JS：_apStationCard 渲染改动要点 ===== */
// 1) 达成率单元格：包成 ap-rate-cell + 进度条（颜色复用现有阈值色 ok/warn/bad）
//    原： tds += '<td class="center">'+_apRateBadge(v)+'</td>';
//    改：
function _apRateCell(v){
  if(v==null) return '<td class="center ap-rate-band">—</td>';
  var c = v>=0.8 ? 'var(--ok,#0F9D58)' : (v>=0.5 ? 'var(--warn,#B9770E)' : 'var(--bad,#E02020)');
  var pct = Math.round(v*100)+'%';
  return '<td class="ap-rate-band"><div class="ap-rate-cell">'+
         '<span style="color:'+c+';font-weight:700">'+pct+'</span>'+
         '<div class="ap-rate-bar"><i style="width:'+pct+';background:'+c+'"></i></div>'+
         '</div></td>';
}
