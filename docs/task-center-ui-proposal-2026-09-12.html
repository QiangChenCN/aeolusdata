针对「任务运行工作台 / 任务中心」全部页面与组件，结合 2026 年主流前端设计实践与行业同类产品（运营后台 / 任务管理 / 数据看板）的设计语言，对现有 UI 与排版进行系统性审计，并输出可直接落地的优化实现方案。

结论速览：当前工作台的设计基础已相当成熟——双层设计令牌、概览首页、横长形任务卡、节点步进条、配置弹窗、明确断点一应俱全。 主要差距集中在五处：① 间距未严格归一为 8pt 网格；② 字号阶梯含离格值（如 23.25px）；③ 响应式仅用视口 @media，未引入容器查询；④ 缺 prefers-reduced-motion 与骨架屏加载态；⑤ 顶栏在 375px 仍结构性溢出、缺关键词/多维筛选。 下文给出 5 大轴、共 18 项的优化清单，每项均标注优先级（P0/P1/P2）并附具体 token / CSS / JS 改动，可直接进入实现。

1调研结论 · 行业主流实践

下列结论来自 2026 年仍在维护的权威设计系统与公开工程实践，作为本次优化的对标基准。

1.1 布局结构 —— 概览优先 + 稳定框架 + 模块化

任务/运营类产品的主流结构是「左侧导航 + 顶栏 + 内容区」三段式，且首屏必含一个概览（Overview）着陆页（KPI 卡 + 快捷入口 + 最近动态），让用户一眼掌握全局健康度，再下沉到具体任务列表（Zigpoll 实时看板研究；ONES 任务管理设计指南）。模块按功能聚类，用留白而非分割线划分。

1.2 信息层级 —— 清晰三级 + 状态优先 + 留白

LobeHub「2025 现代 UI 标准」强调：用尺寸/色彩/间距三件套建立层级；标题与正文要有戏剧性字号差；中性灰 + 单一品牌强调色；慷慨留白降低认知负荷。状态信息（运行中 / 失败 / 待处理）应前置、用色彩编码，而非藏在次级文字里。

1.3 栅格与间距 —— 8pt 基线网格

Atlassian、澳大利亚政府设计系统、Workday Canvas、LobeHub 均明确采用 8px 基准单位。间距刻度建议为 0 / 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96px（4px 仅用于图标/边框微调）。语义约定：4–8px 图标-文字、12–16px 组件内、24px 卡片内边距、32–48px 区块间距、64–96px 页面级留白。

1.4 组件组织 —— Token 驱动 + 三态完备

成熟设计系统（Ant Design 5 / Material 3 / Polaris）的共性是：一切视觉走设计令牌、单一事实来源；每个组件具备默认 / 空 / 加载 / 错误四态；可复用组件库而非页面内联样式。

1.5 响应式 —— 容器查询 + 触控可达

2025 年响应式范式的核心转变是从「视口驱动」到「组件驱动」：用 @container 让卡片按所在容器宽度自适应，而非视口（Josh W. Comeau《Container Queries Unleashed》2025；Ant Design 5 已对 Card/Modal/Drawer 启用）。原则是用 min-width 渐进增强、而非 max-width 降级；老浏览器自动回退到紧凑版。触控目标 ≥44px 是 WCAG 硬性要求。

3优化方案 · 五大轴

每项标注优先级：P0 低风险纯 token/CSS、可立即落地；P1 需少量 JS 交互增强；P2 视图级升级。

轴 A · 布局结构

P1

A1 首页增强：状态化 KPI + 最近运行

现有首页仅有静态统计与快捷卡。增强为「健康概览」：KPI 卡直接反映实时状态（运行中 N / 失败 M / 今日已跑 K），并新增「最近运行」微型列表（取 state.history 前 5 条）。复用现有 .stat / .hrow 结构。

改动
JS renderHome()：读 state.current/queuedIds/last/history 计算 KPI；新增 .home-recent 区块复用 .hlist 样式。
前置
数据已就绪（SSE 已推送 run_start/run_end），无需后端改动。
P2

A2 任务列表：分组小节头 + 列表/看板视图切换

「全部任务」等长列表增加分组小节头（如按业务分组折叠），并提供「列表 / 看板」视图切换。看板视图按状态分列（待运行 / 运行中 / 完成 / 失败），卡片可拖拽改状态（与现有节点拖拽同范式）。

新增
.section-head（标题+计数+折叠箭头）、.view-switch 分段控件、.board/.board-col 栅格。
注意
看板为新增交互范式，需先与老板确认是否纳入本期。
P2

A3 运行记录：二级详情抽屉

点击运行记录行滑出右侧详情抽屉（概要字段 + 内嵌日志 + 产物入口），替代仅靠「看日志」按钮跳转全屏。

复用
现有 .scrim + 右侧抽屉模式（与侧栏同机制），.console 内嵌。

轴 B · 信息层级

P0

B1 统一标题三级映射

固化「视图标题 → 区块标题 → 卡片标题」三级字号，禁止散落自定义。现有令牌已覆盖，仅需在 DESIGN 中定稿映射表并补充可选 --fs-section。

/* tokens.css §14 增补 */
--fs-view:  17px;   /* 视图主标题（现有 --fs-title-xl） */
--fs-section:15px;   /* 区块标题（现有 --fs-title-sm） */
--fs-card:  14.5px; /* 卡片标题（现有 --fs-title-sm 同值） */
P0

B2 状态前置：卡片状态徽章

卡片左侧已有一条状态色条（.card.running/success/failed/queued::before），再在 card-left 顶部补一行「状态徽章」（进行中 / 上次成功 / 上次失败 / 排队中），让状态一眼可读，不依赖滚动到右侧「上次运行」。

现状
状态仅藏于右侧「上次运行」小字 + 左侧细色条。
优化
card-left 顶部一行彩色徽章：● 运行中 / ✓ 上次成功 6.2s / ✕ 上次失败。
P1

B3 空 / 加载三态完备

新增骨架屏 .skeleton（shimmer，受 reduced-motion 控制）用于首屏与 SSE 重连；空态升级为「图标 + 文案 + 建议操作」三件套，替换纯文字 .empty。

/* 骨架屏：shimmer 动画，reduced-motion 下静止 */
.skeleton{background:linear-gradient(90deg,#eef0f3 25%,#e2e6ea 37%,#eef0f3 63%);
  background-size:400% 100%;animation:sk 1.4s ease infinite;border-radius:var(--r-sm)}
@keyframes sk{0%{background-position:100% 0}100%{background-position:0 0}}

轴 C · 栅格与间距（最高性价比）

P0

C1 间距归一为 8pt 网格

保留现有值，补齐 8pt 缺档；将 18/22/34/88 标记为「历史/装饰」离格值，新代码一律走 8 的倍数（对齐 Atlassian / AU Gov / Workday 实践）。

/* tokens.css §17 增补（8pt 倍数） */
--sp-28:28px; --sp-32:32px; --sp-40:40px;
--sp-48:48px; --sp-64:64px;
/* 现有离格值（仅历史/装饰，勿在新代码使用）：18 / 22 / 34 / 88 */
校验
python/workbench/check_tokens.py 已统计裸 px；增补后可加一条「新代码间距须为 8 倍数」规则。
P1

C2 内容栅格语义令牌

新增区块间距与卡片网格 gap 的语义令牌，统一各视图节奏（替代散落的 sp-12/sp-13/sp-18）。

--gap-card:   var(--sp-12);   /* 卡片网格间距 */
--gap-section:var(--sp-24);   /* 区块之间 */
--gap-block:  var(--sp-16);   /* 区块内分组 */
P1

C3 标题引入流式字号

用 clamp() 让视图标题随视口平滑缩放，减少断点跳变（替代固定 23.25px 与 17px 的硬切）。

--fs-title-xl:clamp(15px, 0.6vw + 13px, 17px);
/* 顶栏主标题同理，避免 375px 硬截断 */
--fs-title:clamp(16px, 1vw + 13px, 20px);

P0

D1 统一 .section 容器组件

抽象一个区块容器（标题 + 可选操作位 + 内容槽），所有视图统一包裹，消除各视图手写 margin（如 .home-sec）。

.section{margin-top:var(--gap-section)}
.section-head{display:flex;align-items:center;gap:var(--sp-10);margin-bottom:var(--sp-13)}
.section-head b{font-size:var(--fs-section);font-weight:600}
.section-head .sp{flex:1}
P1

D2 骨架屏组件（见 B3）

与 B3 同源，作为通用加载态组件，首屏 init() 与 SSE 断流重连时渲染。

P2

D3 卡片头统一 .card-h

抽离「图标 + 标题 + 元信息」头部，任务卡 / 流水线卡 / 快捷卡共用，避免三套近似结构。

轴 E · 响应式适配

P0

E1 容器查询驱动卡片布局

给 .tasks / 卡片容器加 container-type:inline-size，卡片内部布局按容器宽度在 ≥520px 走三栏、<520px 堆叠——模态内、窄侧栏等场景天然适配，不再依赖视口断点（Ant Design 5 同做法）。

.tasks{container-type:inline-size}
/* 旧：@media(max-width:820px){ .card{grid-template-areas:"left""mid""right"} } */
@container (max-width:520px){
  .card{grid-template-columns:1fr;grid-template-areas:"left" "mid" "right";align-items:stretch}
  .btn-run{min-width:180px}
}
原则
用 min-width 升级、max-width 降级回退；老浏览器自动走默认紧凑版（渐进增强）。
P0

E2 动效可访问性：reduced-motion

新增全局守卫，尊重系统「减少动态效果」设置（无障碍合规，且零风险纯增量）。

@media (prefers-reduced-motion:reduce){
  *,*::before,*::after{transition-duration:.01ms!important;
    animation-duration:.01ms!important;animation-iteration-count:1!important}
}
P1

E3 顶栏 375px 溢出修复

当前顶栏在 375px 仍溢出（DESIGN §8.6.5 自认结构问题）。方案：≤560px 时顶栏改为两行——第一行 logo+标题+☰，第二行状态胶囊+操作按钮换行；或用 clamp() 标题 + 溢出省略。

@media(max-width:560px){
  .hd{flex-wrap:wrap;height:auto;padding:var(--sp-10) var(--sp-14)}
  .hd-t b{font-size:clamp(15px,4.5vw,17px)}
  .hd .status,#connCap,#quarkCap{order:3}  /* 状态胶囊换行到第二行 */
}
P1

E4 断点治理表

集中登记视口断点（1000/820/620/560）与新增容器断点（520），同步更新 tokens.css §25 与 DESIGN.md §9.4，确保两处一致。

类型断点行为
视口≤1000侧栏转抽屉、出现 ☰
视口≤820运行记录转卡片网格
视口≤620流水线卡单列、隐藏服务胶囊
视口≤560顶栏两行、配置弹窗满宽

P2

E5 关键词 / 多维筛选条

在任务列表顶部增加搜索框 + 状态/分组筛选（行业最佳实践，ONES/Zigpoll 均强调）。与现有左导航分组互补，不冲突。
